# Mobile Apps and Services

Individual development assignment with shared collaboration. Due September 15, 2026.

## Current status

Repository setup only. No iOS sample has been selected or built yet, and no backend has been deployed. The proposed platform is iOS using Swift and SwiftUI; all three participants have a MacBook and iPhone. The app idea is still to be decided.

## Objectives

- Run an existing interactive sample on a physical iPhone.
- Modify the sample and demonstrate Git collaboration with classmates.
- Deploy a backend REST API and connect the app to it.
- Record references, debugging, testing, coordination, and learning.

## Get the repository

```sh
git clone https://github.com/nagarkarvihaan/Mobile-Apps-and-Services.git
cd Mobile-Apps-and-Services
```

Xcode and an Apple Account will be needed for iPhone development. Open Xcode to complete its license and first-run setup. Each participant should use their own Apple Account for device signing.

App build/run instructions, the source sample URL, and the backend API URL will be added after those components exist. Cloning this repository alone does not currently produce a runnable app.

## Working together

1. Accept the repository invitation and clone the code.
2. Create a branch for your change, for example `git switch -c yourname/button-label`.
3. Build and run the existing app before modifying it.
4. Make a small change, test it, and run it on your physical device.
5. Commit, push your branch, and open a pull request describing the change and testing.
6. Have the recipient review and merge it, then fetch/pull, rebuild, and run the change on their device.

Every participant must perform both sides of the exchange and document their own experience. See [collaboration notes](docs/collaboration.md).
